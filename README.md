# POLICY DOMINO — 자동 정책 변경 감시

정부·지자체·공공부문의 공식 공개 게시물을 클라우드에서 정기 수집하는 정책 모니터입니다. 사용자가 정책을 입력하거나 로컬 서버를 실행할 필요는 없습니다.

**공개 웹사이트:** https://dodam-heo.github.io/policy-domino/

## 작동 중인 기능

- 중소벤처기업부, 보건복지부, 행정안전부, 과학기술정보통신부, 서울특별시, 경기도, KOSIS, 국가데이터처의 **공식 RSS 23개 채널** 수집
- 게시 날짜를 한국 시각과 공인 RSS 날짜 기준으로 정규화, 최신 게시일 순으로 첫 화면 표시
- 이전 수집과 비교하여 새 게시물·수정 게시물 감지
- 확정·시행 관련 자료와 입법·행정예고를 다른 단계로 표기
- 공개 페이지에서 원문과 공개 첨부 PDF·DOCX·HWPX를 일부 자동 확인
- 서로 다른 기관의 게시글을 비교하고, 공식 변경자료에 명시된 이전·새 수치와 타 기관 공개문서의 종전 수치가 일치하면 근거 문구·게시 URL·위치를 ‘검토 대상’에 표시
- 정책 변경 확정·수정 의무를 확인하지 못한 관계는 검증 완료로 표시하지 않음
- 매시간 GitHub Actions 자동 수집 및 GitHub Pages 갱신

## 웹 화면

기본 화면은 **최신 게시**입니다. 그 밖에 신규·수정 감지, 게시정보 수정 점검, 변경 검토 후보로 화면을 구분했습니다. 검색은 조회 결과를 필터링할 뿐 정책 감시의 입력 조건은 아닙니다.

## 운영 범위

현재 연결된 23개 공식 채널과 그 페이지에서 발견한 일부 첨부자료·연관 게시물에 한정해 조사합니다. 기관별 게시판 구조, PDF/HWP 접근 제한, 공개 검색 색인 범위 때문에 **모든 기관 홈페이지와 첨부파일을 빠짐없이 전수 검사하는 것은 아직 보장되지 않습니다.**

이는 실제 정책 수정 여부를 자동으로 결정하거나 외부 기관 홈페이지를 변경하는 프로그램이 아니라, **증거 위치를 제공해 담당자가 검증·조치할 수 있도록 하는 감시·조사 시스템**입니다. 지원되지 않거나 읽지 못한 자료는 확인 완료로 간주하지 않습니다.

## 자동 실행

GitHub 저장소의 [Actions](https://github.com/dodam-heo/policy-domino/actions)에서 Policy Domino - Auto Watch and Pages 워크플로를 실행·확인할 수 있습니다. 서버와 Python 라이브러리는 GitHub Actions에서만 실행합니다. 사용자 컴퓨터에는 설치하지 않습니다.

사이트 공개 설정은 [Settings → Pages](https://github.com/dodam-heo/policy-domino/settings/pages)에서 GitHub Actions여야 합니다.
