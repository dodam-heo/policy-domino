# POLICY DOMINO — 정책 변경 연쇄 영향 자동 조사

**목표는 제·개정 게시글을 모으는 일이 아닙니다.** 확정된 법령·제도 변경을 자동으로 발견하고, 그 변경이 미치는 기관·사업·기업의 공개 웹페이지·문서·첨부파일을 찾아 **정확히 어디를 어떻게 바꿔야 하는지** 근거와 함께 알려주는 서비스입니다.

- 서비스: https://dodam-heo.github.io/policy-domino/
- 클라우드 운영: GitHub Actions가 수집·비교·탐색하고 GitHub Pages가 결과를 표시합니다. 사용자 PC에 Python 설치가 필요하지 않습니다.

## 처리 단계

1. 법제처 공포법령 및 중앙부처의 공식 고시 등에서 확정된 변경을 수집합니다. 입법예고·단순 보도자료를 확정된 개정으로 취급하지 않습니다.
2. 공식 원문에서 변경 전→후 수치·문구와 적용시점을 추출합니다. 원문으로 확인되지 않으면 추측해 채우지 않습니다.
3. 기관별 RSS 자료뿐 아니라 공개 검색을 통해 관련 기관·기업·학교의 실제 공개 문서 URL을 찾아 원문과 일부 PDF·DOCX·HWPX를 읽습니다.
4. 공식 변경 전 값이 관련 공개자료에 그대로 남아 있는지 대조하고, 존재하면 기관명·URL·본문 위치·현행값·변경값·근거를 표시합니다.
5. 이미 종료된 연도별 안내문은 과거 기록으로 남겨야 하므로 변경 권고에서 제외합니다.
6. 근거가 부족한 경우 ‘변경 영향 추적’으로 분리합니다. 단순 제목 유사도를 실제 수정 의무로 간주하지 않습니다.

## 화면

기본 탭 **신규·수정 대상**: 실제 공개문서와 종전값의 대응 관계를 확인한 검토사항이 우선 표시됩니다. ‘변경 영향 추적’은 원문 비교·대상 검색의 미확인 과정이며, ‘법령·제도 변경 근거’는 참고 원문 목록입니다.

## 출처 및 검증 한계

법제처 공식 법령 목록·본문 API는 별도 사용자 인증값(환경변수 `LAW_OC` / GitHub Secret `LAW_OC`)이 필요합니다. 인증값이 없으면 법제처 공개 ‘최근공포법령’ 페이지와 각 기관 공식 RSS에서 접근 가능한 자료를 제한적으로 조사합니다. <https://open.law.go.kr/LSO/openApi/guideResult.do>

현재 **전국 모든 홈페이지·첨부문서의 완전한 전수분석이나 모든 개정 조문의 비교까지 검증된 상태는 아닙니다.** 공개검색의 색인 범위, 사이트 접근 차단, 스캔형 PDF 및 HWP의 파싱 제약이 있습니다. 판정 시 적용일·사업 연도·원문 문맥을 사람이 확인해야 할 수 있습니다. 결과를 과장하지 않기 위해 확인된 대상과 조사 대상을 구별합니다.

## 운영 및 상태 확인

- [Pages 설정](https://github.com/dodam-heo/policy-domino/settings/pages)
- `data/deploy_status.json`은 **Pages 배포 성공 후에만** 기록됩니다.
- `data/collection_status.json`은 수집·테스트 실패 시 기본 진단을 기록합니다.
- 최신 수집의 근거 URL 및 조사 결과는 `site/data.json`에 저장됩니다.
